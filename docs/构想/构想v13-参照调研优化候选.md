## AA. MCP 消费面（代理适配工程——codegraph 实测教训）

### AA1. 单强工具与成功形状错误契约
> **状态注记**：**已完成**（2026-11-20，设计稿 #198 D1-D8 全批 → 实施 #199：vrp_query 17 类型单强查询工具+工具面 30→10 分族收敛+`_guard` 捕 `(SystemExit, Exception)` isError 面归零+_INSTRUCTIONS 重组循环重写；MCP server 0.2.0 破坏性收敛）。
- **是什么**：MCP 工具集收敛——默认暴露一个强查询工具（多查询类型聚合，CGC analyze_code_relationships 15 query_type 单工具先例）而非一排窄工具；**可恢复状态绝不返回 isError**——未索引/找不到符号等一律返回成功形状的指引文本（codegraph 实测：`isError:true` 一两次就让代理整个抛弃工具；错误即放弃）。代理引导单源（initialize 响应唯一权威，安装块只指向工具名）。
- **轮子**：**codegraph**（`src/mcp/tools.ts:100-111` NotIndexedError 成功形状；`AGENTS.md` "Adapt the tool"/"错误即放弃"两节；8 工具定义默认暴露 1 的实测结论）；**CGC**（15 query_type 聚合单工具）。
- **判定**：**学**（设计律：适配代理而非改造代理——"让代理已经在调的工具用它已经给的输入做更多事"；措辞引导实验 3 变体全回归的教训）+**造**（VRP MCP server 工具面收敛改造）。
- **成本**：低-中。优先级：**亮点**。

### AA2. 自适应输出预算与 per-tool 限额/超时/截断
> **状态注记**：**已完成**（2026-11-20，实施 #199：L1 24K 硬顶+JSON 感知确定性收缩（`vrp/mcp_budget.py` emit/_truncated 备注）/L2 静态限额中央表+VRP_TOOL_RESULT_LIMITS env/L3 自适应档位否决诚实记档（YAGNI）/L4 progress_handler 超时（nav_path 300s=10× 实测律对齐 CGC、query_facts 10s 保留）+VRP_TOOL_QUERY_TIMEOUT env/L5 输入上界 1MiB-10K；魔数全测试钉死）。
- **是什么**：查询输出预算随库规模单调（codegraph 双层预算：调用数 1-5 次/输出 13K-24K 字符，硬顶 ~24K 内联上限防宿主外置文件；"更大档不得更小每文件额度"单调性不变量）；per-tool 结果条数上限+查询超时+截断可见告警（CGC TOOL_RESULT_LIMITS/TOOL_QUERY_TIMEOUTS，超时按真实规模校准并写明出处）；输出预算类魔数必须回归测试钉死（codegraph ITER1/2/3 反复横跳教训）。
- **轮子**：**codegraph**（`src/mcp/tools.ts:265-409` getExploreBudget/getExploreOutputBudget 两函数+单调不变量）；**CGC**（`utils/tool_limits.py`；"168,745 函数图上 find_dead_code 12s→默认 120s=10×"校准法）。
- **判定**：**学**（预算档位与校准方法）+**造**（facts.db 规模查询+MCP 输出打包层，纯 stdlib）。
- **成本**：中。优先级：**亮点**（与 AA1 合批实施更佳）。

### AA3. GCF 压缩编码（token 优化）
- **是什么**：MCP 响应键声明一次+值管道分隔的紧凑编码，降 token ~62%（CGC 实测，前沿模型 100% 可读，环境变量 opt-in，无解码器回退 JSON）。
- **轮子**：**CGC**（`CGC_OUTPUT_FORMAT=gcf`；`utils/gcf_encoder.py`）。
- **判定**：**学**（编码语义）+**造**（dossier/report 的 MCP 输出面加可选编码层）。
- **成本**：低。优先级：甜点偏后（AA1/AA2 落地后收益才显现）。
> **状态注记**：**已完成**（2026-11-21 甜点穿插批 #210）——`vrp/gcf.py`（CGC gcf_encoder 语义：键声明一次+值管道分隔；dict 两行/全等键 list[dict] 键声明一次逐行记录（token 主收益面）；混合形状诚实回退紧凑 JSON——强编码=模型侧断列歧义宁缺勿错；值内反斜杠·换行·`|` 三转义防断列）+`VRP_OUTPUT_FORMAT=gcf` opt-in（CGC_OUTPUT_FORMAT 同律；大小写宽容）接线 mcp_budget.emit 单收口点（全部工具输出经此）；**超帽回退 JSON 收缩链**（GCF 面不收缩——JSON 感知收缩算法锚定 JSON 结构（最长列表对半截），GCF 扁平结构无此锚点，诚实边界）；无解码器（前沿模型直读），回退=不设 env 即 JSON 默认面零动；AA1/AA2 前置已齐（#199）——emit 收口先在，本批是收口点上的可选编码层。

## BB. 事实质量面（置信度与审计——CGC 自审报告教训）

- **是什么**：edges 表 CALLS 边加 resolution_tier+confidence+label（EXTRACTED/INFERRED/AMBIGUOUS）列——解析确定性显式入图；下游静态分析（死代码判定/环检测/slices）按置信度过滤，AMBIGUOUS 边不参与"必死"判定只参与提示，误报治理从源头解。
- **轮子**：**CGC**（9 级 tier 0.08-1.00 分层+tier≥8 写独立 HEURISTIC_CALLS 表；`resolution/calls.py:65-86`；embedded_schema CALLS 边列）；**codegraph**（edges.provenance 列 tree-sitter|scip|heuristic+合成边 synthesizedBy/registeredAt 元数据——"部分覆盖比没有更糟"端到端原则）。
- **判定**：**学**（分层语义与阈值）+**造**（facts_schema edges 迁移+ETL 解析路径标注；schema 迁移走既有面）。
- **成本**：中-高（动 schema+ETL 标注面）。优先级：**亮点/硬核**（需设计稿）。
- **状态**：**已完成**（2026-11-21，#205 批⑦）——设计稿 docs/设计稿-BB1V17-调用边置信度分层与schema迁移矩阵.md（用户授权自批 D1-D8）；实施前重读 CGC `resolution/calls.py:65-86` 防转述失真+三仓真值探针（自仓/lusiem/tsa）实证 evidence/strategy 值空间开放不可枚举→label 判据=confidence 双阈值（≥0.85 EXTRACTED/≥0.70 INFERRED/<0.70 AMBIGUOUS；None→NULL 未知不惩罚）；edges 加 resolution_label 列（裸 label 与 symbols.label 词汇冲突弃；CGC confidence_label 弃）；标注范围只 CALLS/CALL_REFERENCE 族；v_dead_code 拆分+AMBIGUOUS 过滤（`IS NULL OR != 'AMBIGUOUS'` 防 SQL 三值逻辑坑）+MENTIONS/SPAWNS 独立；schema 迁移走 V17 迁移链（user_version=2）；**诚实修正记档**：原文"resolution_tier"未实施——CGC tier 是其解析器内部枚举，VRP 消费 CBM 事实而非 CGC 解析器输出，tier 无数据源，不加列（confidence 已有+label 落地）。
