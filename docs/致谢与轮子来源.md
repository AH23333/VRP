# 致谢与轮子来源（Z28）

> 本项目的很多设计不是发明的，是**学来的**。这一页公开致谢所有学过的工具、框架与文献，并公开我们的学习方法论。上游若看到此页：感谢，你们的工作直接塑造了这个项目的形态。

## 轮子学习方法论

本项目对外部工具奉行"学形态不引依赖"（#147-#150 轮子学习系列批次沉淀的纪律）：

1. **造/绕/不造三判定**：每个候选需求先轮子调研，明确判定——造（自实现）/绕（用现成的）/不造（暂缓），判定与理由随构想文档落档（构想 v10/v11/v12 三批 71 项逐项可查）。
2. **学形态不引依赖**：运行时零第三方依赖是红线；学的是设计形态（如 argcomplete 的 argparse 内省法、Sentry 的 fingerprint 聚组语义），不是引入包。
3. **探针先行**：动工前先写探针实证（四面双态、病理案例、真实仓冒烟），不凭文档想象写代码。
4. **红面自证**：改完先证明测试能红（stash 源码复跑），再证明绿——防止守卫假绿。
5. **宁缺勿错**：不确定的能力边界明示（如 `vrp profile` 不做幂律拟合，用 top1%/top10% 集中度做诚实替代），不假装有能力。
6. **只引公开声明**：谈论竞品/上游只用其公开文档声称的内容（见《竞品对照矩阵.md》）。
7. **立项前复轮子调研**：立项时点复检上游生态（附时点），防止调研过期。
