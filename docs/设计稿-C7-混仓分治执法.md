# 设计稿：C7 混仓分治执法

状态：**待批准**（总表批③；构想v10 C7 立项；起草前现状源码逐行重读核验——`s7_enforce.py` run 路由/混仓拒绝点/`_write_findings` replace-all、`s7_enforce_ts.py` 同型写面、`assess.py` 混仓警告、21 引擎快测 mixed 件清单；语义参照 Bazel visibility/Nx enforce-module-boundaries 官方文档 2026-11-20 拉读，防转述失真纪律兑现）

## 1. 现状与增量（诚实盘点）

- **混仓直接拒绝（本批要消灭的缺口）**：`s7_enforce.run()` 求值全部 21 引擎容器 → `langs` 列表 → `len(langs) > 1` → `not-enforceable`（`"mixed-language structure (py + ts): split per language into separate structures"`，s7_enforce.py:590-599）。monorepo 是主流仓形态，这是剩余项里唯一"直接拒绝真实场景"的能力缺口（构想v10 C7 判定原文）。
- **"分"已隐式存在**：每语言 `derive_X_containers` 已按语言过滤容器；`build_contracts(payload, containers)` 只对**传入的**容器生成契约（`_layer_map` 层→容器并集）——把某语言自己的 containers 传给它的引擎，天然得到该语言子集的层 DAG 契约。分治缺的只是调度与写面组合，印证"纯组合"立项判定。
- **组合缺口一（写面互斥，最高危）**：每引擎 `_write_findings` 各自 `DELETE FROM findings WHERE source = 's7-enforce'` 再 INSERT（幂等 replace-all，s7_enforce.py:426 / s7_enforce_ts.py:207，×22 同型站点）。顺序执行两引擎 = 后者清空前者 findings——分治若不处理，py+ts 混仓只有最后跑的语言留下违例，**静默丢数据**。
- **组合缺口二（路由形态）**：单语言执行是 ~150 行 if/elif 链（s7_enforce.py:600-750），每语言有定制前置（`timed_out` 检查→enforcer-failed）与后置（`orphan_*_files` 键合并）。分治直接复写这段 = 两处维护同漂移面。
- **组合缺口三（跨语言边）**：跨语言模块依赖边（py→ts、go→rs 等）无任何引擎判定。CBM `edges` 表有数据（`src_fid/dst_fid/type/evidence/line`，schema 见 vrp/schema/facts_schema.sql）；构想v10 C7 原文："跨语言边经 CBM 边关联上报（不参与层判定）"。
- **消费面（已核，无字段级锁死）**：`cmd_enforce` print JSON（cli.py:501-509）；MCP enforce 工具直通（mcp_server.py:369，经 `_guard`/emit）；auto_curate 写 `04-enforce.json`（auto_curate.py:372-373，dict 整体落盘无字段依赖）。新聚合形态安全。
- **警告文案待同步**：assess.py:163-169 混仓警告尾注 `"(currently not-enforceable)"`（T10 #157 埋的"C7 立项后改写"伏笔）。
- **测试面**：21 引擎快测文件各 1-2 件 mixed 拒绝件（~22 处 assert "mixed-language"）+ `test_assess_mixed_language_warning` 1 件——C7 后全部翻为分治绿路径。深测 21 文件全部单语言仓，不受影响。

## 2. 参照源码重读记实（file:line / 文档锚点）

- **Bazel visibility**（bazel.build/concepts/visibility，2026-11-20 全文拉读）：目标级 visibility 在 **analysis 阶段对每条依赖边**判定——"A target will fail to build during the analysis phase if it violates the visibility of one of its dependencies"；包级声明 + `package_group` 复用；Bazel 跨语言统一是因为**一切皆 target 于一张图**。VRP 无统一跨语言依赖图（各引擎源级解析彼此不通），跨语言边只上报不判定是**诚实差距**（非偷懒）——与 Bazel 的差距记档不遮掩。
- **Nx enforce-module-boundaries**（nx.dev/features/enforce-module-boundaries，同日全文拉读）：**双轨制**——JS/TS 项目用语言内 ESLint lint 规则（`@nx/enforce-module-boundaries`），任意语言用 Conformance 图级检查（`nx conformance:check`，Nx 图上跑）；同套 tag 约束（`sourceTag → onlyDependOnLibsWithTags`）；违例报"**跨边界的那条依赖**"本身。"语言内各自执法 + 图级跨语言面"正是 C7 分治的形态先例；VRP 的"图"=CBM edges，且只上报不判（无 Conformance 的图完备性，诚实降级）。
- **本仓现状锚点**：s7_enforce.py:480-599（run 路由+derive 全量求值+混仓拒绝）、:425-476（py `_write_findings` replace-all+`_anchor_for` 锚定）、s7_enforce_ts.py:205-236（ts 同型写面，锚定=违例文件首符号——**各引擎 anchoring 是语言特异知识**）、:590-599（拒绝点）、`_layer_map`/`_forbidden_pairs`/`build_contracts`（层 DAG→契约，语言无关纯函数）；assess.py:163-169（警告文案）；`_s7_engine_suffixes()`（assess.py，扩展名→引擎映射实时取引擎常量——#157 建立的单一事实源，跨语言边语言分类直接复用）。
- **空缺点确认**（构想v10 C7 轮子调研复核）：deptrac/ArchUnit/import-linter 全单语言；无专门"混语言架构执法"轮子——Bazel visibility 是构建系统内建、Nx Conformance 是图级企业件，均不可引依赖（零第三方红线），语义参照后自造调度层。

## 3. 分治调度设计

- **判定与分派不变**：derive 全 21 引擎照旧一次性求值（今日行为，成本不变）；`langs` 列表照旧（固定序 = 路由元组序，确定性锚）。
- **单语言路径字节级不变**：`len(langs) == 1` 走既有路径零改动（21 个深测文件 + 既有快测为锚——分治是**纯增量**，不重写单语言行为）。
- **`len(langs) > 1` → 分治循环**：
  1. **单次清场**：`DELETE FROM findings WHERE source = 's7-enforce'` 一次（工具级 replace-all 语义保持：一次 run 一次清场，与今日单语言 run 等价）；
  2. **逐语言执行**（langs 固定序）：每语言走该语言 runner（表驱动，见下）——`run_X(..., write_findings=False)` → 该引擎 `_write_findings(..., replace=False)` 只插不删 → timed_out 前置与 orphan 后置按该语言既有语义；
  3. **跨语言边关联上报**（§4）；
  4. **聚合 result**（§5）。
- **表驱动重构（消除缺口二）**：if/elif 链提取为模块级 `LANG_RUNNERS` 表（name → (derived, pre_check, runner, post_merge)），单语言与分治**共用同一张表**——单语言 = 表里查一个，分治 = 表里按 langs 序遍历。单语言 result 形状字节级不变由深测锚定；表是唯一执行定义点（两处复写漂移面消除）。

## 4. 跨语言边关联上报（不参与层判定）

- **数据源**：facts.db `edges ⋈ symbols`（src_fid→file_path，dst_fid→file_path）。
- **语言分类**：file_path 扩展名 → 引擎（复用 `assess._s7_engine_suffixes()` 映射，#89 单一事实源——不另写后缀表）。
- **模块归属**：structure `modules[].symbol_fids` → symbols.file_path → 文件→模块 id 集合（一文件可属多模块，模块对全组合上报，确定性排序）。
- **上报形态**：result JSON 增 `cross_language_edges`：按 `(src_module, dst_module, src_lang, dst_lang)` 聚合 → `{pair, count, types(计数分解), sample_edge(首条，(src_fid,dst_fid,type) 确定性选)}`；count 降序+键升序确定性排序；**top 100 cap** + `cross_language_edge_groups_total` 诚实总组数（超 cap 不假装没有）。
- **只入 result 不写 findings**：跨语言边不产生 P9（"不参与层判定"=不进 dossier 病理面——写 findings 会暗示判定，越权）；只上报**两端均属 structure 声明模块**的边（未关联文件的跨语言边是索引面噪音，结构执法面不收）。

## 5. 聚合 result 形态

- `status` 聚合：全部语言 ok → `"ok"`；全部语言同态 S → S（如全 not-enforceable）；否则 → **`"partial"`**（新 status 值）+ `languages` 每语言明细。
- `languages`：`{lang: 该语言引擎 result 公共字段}`（step/engine/status/contracts/violations/kept/broken/...）；`violations` 顶层 = 各语言和。
- **新 status 值消费面安全（已核）**：cmd_enforce print / auto_curate 落盘 / MCP 直通均无 `== "ok"` 比较依赖；tx 闸门不读 enforce status。
- **timeout per-engine 全额不均摊**：每引擎拿完整 timeout（单语言行为不随仓形态漂移）；分治 wall clock 最坏 N×timeout 诚实记档于 result（`timeout_note`）。

## 6. 引擎面机械改动（×21，每引擎 2 处）

- `run_X(..., write_findings: bool = True)`：`False` 时跳过内部 `_write_findings` 调用，result 附 `_raw_violations` / `_contracts`（私有传输键，docstring 注明 wrapper 内部契约）。
- `_write_findings(..., replace: bool = True)`：`False` 时跳过 DELETE（清场已由 wrapper 完成）。
- 默认值 = 今日行为：**全部既有测试零改动通过**；各引擎 anchoring 逻辑零动（语言特异知识保持各引擎私有——不抽公共 writer，抽了就要复刻 21 种锚定，单一事实源反例）。

## 7. 红线核对

- facts.db 写路径：findings replace-all **工具级**语义保持（一次 run 一次清场+全量插入）；structure/curate/enforce 锚定链零动。
- 确定性：langs 固定序；跨语言边聚合/cap/选样确定性排序；表驱动不引入迭代序变化（dict 插入序即路由序）。
- 单语言零漂移：路径不变，21 深测文件锚定（分治纯增量）。
- 零第三方运行时依赖：调度/聚合/边查询纯 stdlib（sqlite3/json/collections）。
- 同 facts.db 字节级同产物：findings 写入行内容不变（同 payload 同锚定），只有写入时序组合变化。

## 9. 决策点（需批准）

- **D1 分治形态**：langs>1 逐语言执行；单语言路径字节级不变；if/elif 链表驱动化（LANG_RUNNERS 单语言/分治共用）。
- **D2 写面互斥解法**：wrapper 单次清场 + 引擎机械参数（`write_findings=False`/`replace=False`）。备选"findings 快照重插"（零引擎改动）诚实记档**否决**——隐式时序技巧违显式契约纪律，且 findings 行 id 语义脏。
- **D3 跨语言边**：CBM edges × 模块对聚合 + top 100 cap + 诚实总组数；只入 result JSON 不写 findings 不参与层判定；语言分类复用 `assess._s7_engine_suffixes()`。
- **D4 status 聚合**：全 ok→ok；全同态→该态；否则 partial+languages 明细（新 status 值，消费面已核安全）。
- **D5 .h 归属**：沿既有运行时规则（.c 存在归 c 引擎，纯 .h+.m 归 objc）；c+objc 分治不重复执法 .h（既有归属逻辑不动）。
- **D6 timeout per-engine 全额不均摊**（分治 wall clock 最坏 N×timeout 于 result 记档）。
- **D7 assess 警告文案更新**：去 "(currently not-enforceable)"，改分治执法提示（T10 伏笔兑现）。
- **D8 单批实施**（①-④一次过；拆批会让 22 件 mixed 翻新做两轮）。
