## 按角色读

- **接手维护者**：《产品目标.md》→《交接文档.md》（从最新条目往回读）→《踩坑历史.md》→《glossary.md》
- **AI 生产方**（写事务/梳理工件）：《契约/事务契约.md》→《契约/梳理工件契约.md》→ `skills/vrp-loop` + `skills/vrp-curation`；动 schema 先读《契约/schema版本承诺.md》
- **想立项新功能**：《调研/优先级总表-44项重排.md》定优先级 →《构想/v10-v13》候选池找同类项 → 任一已实施设计稿当模板成稿 → 交接文档记批
- **想懂某段历史**：交接文档对应批次条目 → 该批设计稿/构想 →《踩坑历史.md》
- **外部消费方**（CI/出圈）：《评估/SARIF-CI消费指南.md》→《评估/A-B评估协议-防侧信道.md》
