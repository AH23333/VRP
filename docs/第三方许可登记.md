## 四、兼容性结论

1. 上表全部 license（MIT/ISC/BSD-2-Clause/BSD/Apache-2.0/MPL-2.0/OFL）均为宽松或文件级弱著左许可，**相互兼容且与本仓任何常见开源分发方式兼容**；无 GPL/AGPL 类强著左组件。
2. MPL-2.0（hypothesis/pytest-rerunfailures）为文件级著左：其源码修改须开源，不影响链接/调用方；本仓未修改这些包源码。
3. **本仓自身 license 现状（登记时点事实）**：仓库根目录未声明 LICENSE 文件，pyproject.toml 未声明 license 字段。**分发 vrp.pyz/发布 Release 前须确定本仓 license**——届时本表第一节的随仓分发义务（MIT 声明保留/Apache-2.0 NOTICE）即生效。此处只登记事实，不替项目决定 license 选择。
4. 升级组件时按《vendored-上游跟踪规范.md》第 5 步复核 license 并同步本表。
