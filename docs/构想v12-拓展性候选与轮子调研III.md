# 构想v12 — 拓展性候选与轮子调研 III

> 状态：发散清单（未立项）。与《构想v10》（A-G 十八项）/《构想v11》（H-Q 二十五项）正交的第三批维度（R-Z 九组 28 项）。
> 方法论同前两批：**先找轮子再决定造/学/绕**；轮子名单只收确认存在的工具（宁缺勿错）。
> 优先级直觉：亮点=R1/S7/R2（原创组合与治理闭环）；甜点=小时级成本；硬核=需设计稿。

## R. 分析科学面（facts.db 的科学视角）

### R1. 网络科学指标
- **是什么**：调用图作为网络——PageRank 找核心节点、LPA 标签传播社区检测、k-core 分解；**LPA 社区与 propose 聚类对账**（AI 提的模块 vs 图论社区，分歧即发现）。
- **轮子**：**networkx**（算法参考——PageRank 幂迭代/LPA 标签传播；环境有 3.6.1 但运行时零依赖红线→自实现简化版；v9 手写 FR 迭代先例）；**igraph**（大规模图算法形态参照）。
- **判定**：**学**（算法定义）+**造**（简化实现：PageRank 幂迭代/LPA 纯 stdlib 百行级）。**原创组合**：社区检测×propose 对账是"AI 梳理 vs 图论"的交叉验证，叙事完整。
- **成本**：中。优先级：**亮点**。

### R2. co-change 隐式耦合边
- **是什么**：git log 挖掘文件共现矩阵→"改 A 必改 B"成为 facts.db 一等公民边类型（CO_CHANGED）——显式调用边之外的隐式耦合入图，slices/structure 验证器与 dossier 影响面可消费。
- **轮子**：**code-maat**（Tornhill co-change 矩阵——挖掘算法权威）；**CodeScene**（temporal coupling 商业实现参照）。
- **判定**：**学**（共现窗口与阈值语义）+**造**（边类型扩展走 facts_schema.sql 迁移；ETL 面=git log 解析纯 stdlib）。与 v10-A1 区分：A1 是度量曲线，这是边入图。
- **成本**：中-高（动 schema+ETL）。优先级：**亮点/硬核**（需设计稿）。

### R3. 复杂度度量族
- **是什么**：圈复杂度/认知复杂度/可维护性指数入 pathology 面。
- **轮子**：**lizard**（多语言圈复杂度——21 语言覆盖形态参照）、**radon**（Python 复杂度度量权威）、**SonarQube 认知复杂度**（认知复杂度白皮书定义）。
- **判定**：**学**（度量定义与阈值惯例：圈复杂度>10 告警线）+**造**（每引擎的 AST 面上加复杂度计数——21 引擎逐个加，per-language 分步）。
- **成本**：中（21 语言面广）。优先级：甜点偏后（py/ts 先行验证形态）。

### R4. 仓库数字画像
- **是什么**：描述性统计体检——耦合分布 Gini 系数/模块大小幂律检验/边密度/扇入扇出分布——census 的统计深化。
- **轮子**：**scc/tokei**（语言统计形态参照）；**complexity-report**（度量报告先例）。
- **判定**：**造**（纯 stdlib 统计——Gini/幂律拟合百行级；输出进 dossier 或独立报告）。
- **成本**：低。优先级：甜点。

## S. 管道自身智能化（finding 质量闭环）

### S5. finding 聚合
- **是什么**：同根因 finding 去重聚类（一个环产生 N 条 finding→归组呈现）。
- **轮子**：**Sentry grouping**（fingerprint 聚组语义）。与 v10-B6 区分：那是外部日志证据源，这是自家 finding 面。
- **判定**：**学**（指纹设计：根因符号集哈希）+**造**（dossier/report 聚合呈现层）。
- **成本**：中。优先级：甜点。

### S6. finding 优先级评分
- **是什么**：置信度×影响面×修复成本估计→finding 排序（现在是无序清单）。
- **轮子**：**SonarQube quality gate**（评级与阈值语义）。
- **判定**：**学**（评分维度设计）+**造**（公式开放可解释——不学黑盒，权重进 structure JSON 可配）。
- **成本**：低-中。优先级：甜点偏后。

### S7. 反馈环降权
- **是什么**：verdict/拒绝历史反馈进 finding 优先级——AI 老拒绝某类 finding→自动降权；**治理闭环原创点**（decisions 表底座已有）。
- **轮子**：**推荐系统隐式反馈**（协同过滤思想——无专门"架构 finding 降权"轮子=空缺点）。
- **判定**：**造**（decisions 表聚合统计→规则化降权；**红线：降权不删除**——finding 仍在，只调序+留痕原因）。
- **成本**：中。优先级：**亮点**（原创，与 curate 闭环叙事衔接）。

### S8. 阈值敏感度分析
- **是什么**：各引擎阈值扫描输出敏感度曲线（帮用户选 jscpd 阈值/deadcode 天数）。
- **轮子**：**scikit-learn validation curve**（超参敏感度曲线概念——只学形态不引入）。
- **判定**：**造**（阈值扫描=同仓多次跑引擎，输出 finding 数×阈值曲线 JSON+图）。
- **成本**：低-中。优先级：探索（先攒真实"选阈值难"案例）。

## T. 消费者特化输出

### T9. PR review 格式输出
- **是什么**：finding→GitHub review comments 格式（本地生成 JSON/patch 留档供人贴——零服务端红线内）。
- **轮子**：**reviewdog**（review comment 格式与行锚定语义）；GitHub Review Comments API schema（格式权威）。
- **判定**：**学**（comment payload 格式）+**造**（SARIF→review comments 转换器；行锚定复用 report 链 #L{n} 经验）。
- **成本**：低-中。优先级：甜点。

### T10. 迁移前评估报告
- **是什么**：目标仓"上 vrp 前评估"——census+probe+预估命中哪些病理+收益预估，**降低试用门槛**。
- **轮子**：**SonarQube onboarding scan**（首次扫描形态）；**Code Climate quickstart**（接入流程参照）。
- **判定**：**造**（census/probe 已有，差组装+预估叙事模板）。
- **成本**：低-中。优先级：**甜点**（新仓接入直接受益）。

### T11. 代码导览报告
- **是什么**：面向新人的模块导览（每模块一句话职责+建议阅读顺序）——curated 数据已有，叙事模板不同。与 v10-E14 skill 区分：这是输出产物非操作协议。
- **轮子**：**VS Code Code Tour**（导览步骤化形态）；**Diátaxis tutorial**（教学文档结构）。
- **判定**：**造**（curate 消费面新增导览模板）。
- **成本**：低。优先级：甜点偏后。

### T12. executive summary
- **是什么**：非技术一页纸（技术债量化+风险热力+趋势箭头）。
- **轮子**：无现成轮子（原创——"架构债高管一页纸"工具缺位）。
- **判定**：**造**（dossier 消费面+措辞模板）。风险：措辞主观性强，先攒用户需求。
- **成本**：中。优先级：探索。

## U. 部署形态/分发

### U13. zipapp 单文件分发
- **是什么**：`python vrp.pyz`——stdlib zipapp 打包，**零安装试用**（比 pipx 门槛更低）。
- **轮子**：**zipapp**（stdlib——零新依赖）；**pipx/uv**（安装生态定位参照：pipx 是"已决定用"后的安装，pyz 是"试用前"的触达）。
- **判定**：**绕**（stdlib 直接用；vendored 资源打包验证是主要工作——zip 内资源路径访问）。
- **成本**：低-中。优先级：**甜点**（发布分发面补全，配合 v0.1.3 可做）。

### U14. `vrp docs` 本地文档
- **是什么**：docs/ 打包进 wheel+`vrp docs` 本地打开。
- **轮子**：**wheel data files**（打包机制——MANIFEST.in/package-data）。
- **判定**：**造**（打包配置+打开浏览器动作）。
- **成本**：低。优先级：探索。

### U15. shell 矩阵验证
- **是什么**：run_tree 进程治理在 PS 5.1/Pwsh7/cmd/bash/Git-Bash 下行为矩阵测试（现只实测 PS 5.1）。
- **轮子**：**rustc CI 矩阵**（多平台测试面组织思想——本地脚本矩阵非 CI）；**GitHub Actions matrix**（矩阵命名参照）。
- **判定**：**造**（本地矩阵探针脚本；不引 CI——三红线）。
- **成本**：中（每 shell 的进程树击杀语义差异需逐个实测）。
- **优先级**：探索（出跨 shell bug 时再补——坑驱动）。

### U16. 容器运行说明
- **是什么**：Docker 内跑 vrp 注意事项文档（git/locale/时区/进程击杀信号面）。
- **轮子**：Docker 官方 Python 镜像惯例（文档参照）。
- **判定**：**造**（纯文档；风险点预研：POSIX 进程组击杀在容器 PID 1 的行为）。
- **成本**：低。优先级：探索。

## V. Schema 演进/数据契约

### V17. schema 迁移测试矩阵
- **是什么**：facts.db 旧版本库→新版本 upgrade 路径全覆盖测试。
- **轮子**：**Django migrations/alembic**（迁移链思想：线性链+每步测试）；**sqlite3 user_version**（SQLite 原生 schema 版本机制）。
- **判定**：**学**（迁移链组织）+**造**（旧版库 fixture 集合×迁移路径断言——本仓 schema 变更频率低，成本可控）。
- **成本**：低-中。优先级：探索（下次 schema 变更时顺势建立）。
- **状态**：**已完成**（2026-11-21，#205 批⑦ rider）——"下次 schema 变更时顺势建立"触发条件兑现（BB1 动 schema）：`etl.py` `MIGRATIONS` 线性迁移链（学 alembic 链思想零依赖自建——先 ALTER 后 executescript 视图硬约束）+`PRAGMA user_version = 2`+旧版库 fixture 矩阵（tests/test_migrations.py 8 件：v0 升级/幂等/视图替换/链形状/半迁移探测/迁移后写入面）。

### V18. 只读 API 稳定化
- **是什么**：facts.db 表结构对外部工具的版本承诺（schema 兼容政策文档化——第三方直接读库的契约）。
- **轮子**：**semver**（版本语义）；JSON Schema versioning 实践（参照）。
- **判定**：**造**（政策文档+schema 版本号对外文档化）。**反向风险**：公开承诺=变更成本上升——发布早期（v0.x）宜承诺"破坏性变更随 minor 走"宽松政策。
- **成本**：低（文档）。优先级：探索。
- **状态**：**已完成**（2026-11-21，#205 批⑦ rider）——政策文档定稿 docs/schema版本承诺.md：user_version 语义/N-1 库可迁移承诺/v0.x"破坏性变更随 minor"宽松政策（本节反向风险记档落地）/迁移链工程规则/v1 保留基线槽说明。

### V19. 事件溯源
- **是什么**：ETL/curate/transact 全操作 append-only 事件流（审计+回放）。
- **轮子**：**event sourcing**（Fowler 模式文章）；**git reflog**（本地操作日志形态）。
- **判定**：**造**（事件表+回放器）。成本高；verdicts JSONL 已是局部先例。
- **成本**：高。优先级：探索（V17/V18 稳定后再议）。

## X. 极端规模

### X22. 超大仓分片索引
- **是什么**：>10 万符号仓的目录树分片 ETL（ATTACH 分库）——J8 增量化（v11）的**姊妹问题**（横向分区 vs 纵向增量）。
- **轮子**：**SQLite ATTACH**（分库查询官方机制）；**Vitess/分库分表**（分区键选择思想——过重，只取"分区键=目录前缀"的直觉）。
- **判定**：**造**（需设计稿：分区键/dossier 跨分库聚合/复现性红线在分库下的语义）。**真实需求未证**：现有最大 dogfood 仓（tsa 1.5 万 finding）未触瓶颈——**先攒规模案例再立项**。
- **成本**：高。优先级：探索（J8 先行）。

### X23. 资源预算模式
- **是什么**：内存/时间硬顶+分级降级（超预算砍深度不砍全——诚实标注降级面）。
- **轮子**：**v9 §4 cap 降级路径**（本仓先例——超大仓数据切片 cap 降级+诚实标注）；`--budget` flag 已有雏形（超时预算）。
- **判定**：**造**（预算探测器+降级矩阵：哪个引擎先降级、降级如何呈现）。
- **成本**：中。优先级：探索（与 X22/J8 联动：增量/分片落地时一并设计）。
