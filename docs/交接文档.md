## 关键约定

- findings 幂等：每引擎固定 `source`（'etl'/'s2-astgrep'/'s2-deadcode'/'s2-knip'/'s2-vulture'/'s2-jscpd'/'mutate-run'/'ai-gate'），写入前 `DELETE WHERE source=?`；ledger 每工具独立 category
- runtime_evidence 双命名空间：freeze 拥 RUNTIME_SLOTS（callee_key=slot 名）；mutate-run 用 caller_key=callee_key='mutate-run' 自有行（写入前 DELETE WHERE caller_key='mutate-run'），互不干扰、均跨 etl 存续（OWNED_TABLES，#68 审计语义）
- 自有组（annotations/gate_results/transactions/dossier_views/baseline/runtime_evidence + 非 etl findings）ETL 重建时快照回灌；派生组可重建（#68：runtime_evidence 审计语义必须跨 etl 存续）
- validate_anchors **文件为真**：window 哈希对仓库文件重算，不信库内快照；注解四态 active/cosmetic/stale/rejected
- 证据闸门：AI claim 必须 quote 真实行文本，否则拒（source='ai-gate'）
- 旧 facts.db 遇缺新表：rw 打开自动 `ensure_schema`（schema 全 IF NOT EXISTS，幂等）
- CBM 命名 = 仓库名（默认）；旧手命名 DB 已清理
