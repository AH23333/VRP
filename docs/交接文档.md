## 关键约定

- findings 幂等：每引擎固定 `source`（'etl'/'s2-astgrep'/'s2-deadcode'/'s2-knip'/'s2-vulture'/'ai-gate'），写入前 `DELETE WHERE source=?`；ledger 每工具独立 category
- 自有组（annotations/gate_results/transactions/dossier_views/baseline + 非 etl findings）ETL 重建时快照回灌；派生组可重建
- validate_anchors **文件为真**：window 哈希对仓库文件重算，不信库内快照；注解四态 active/cosmetic/stale/rejected
- 证据闸门：AI claim 必须 quote 真实行文本，否则拒（source='ai-gate'）
- 旧 facts.db 遇缺新表：rw 打开自动 `ensure_schema`（schema 全 IF NOT EXISTS，幂等）
- CBM 命名 = 仓库名（默认）；旧手命名 DB 已清理
- 含 `$` 或嵌套引号的命令一律落文件执行（踩坑 #11/#22/#32）
- ast-grep 新规则：先写探针脚本验证 pattern，再进 rules/s2/（pattern 细节多，勿凭记忆写）
