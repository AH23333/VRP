## 关键约定

- findings 幂等：每引擎固定 `source`（'etl'/'s2-astgrep'/'s2-deadcode'/…），写入前 `DELETE WHERE source=?`
- CBM 命名 = 仓库名（默认）；旧手命名 DB 已清理
- 含 `$` 的命令一律落文件执行（踩坑 #11）
- ast-grep 新规则：先写探针脚本验证 pattern，再进 rules/s2/（pattern 细节多，勿凭记忆写）
